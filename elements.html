Valid Elements in HTML5

Basic HTML
Tag Description Attributes
<!DOCTYPE> Defines the document type
<html> Defines an HTML document
<head> Contains metadata/information for the document
<title> Defines a title for the document
<body> Defines the document's body (content structural element) onafterprint, onbeforeprint, onbeforeunload, onerror, onhashchange, onload, onoffline, ononline, onpagehide, onpageshow, onpopstate, onresize, onstorage, onunload
<!--...--> Defines a comment
<h1> to <h6> Defines HTML headings
<p> Defines a paragraph
<br> Inserts a single line break
<hr> Defines a thematic change in the content

Formatting
Tag Description Attributes
<abbr> Defines an abbreviation or an acronym title
<address> Defines contact information for the author/owner of a document/article
<b> Defines bold text
<bdi> Isolates a part of text that might be formatted in a different direction from other text outside it dir
<bdo> Overrides the current text direction dir
<blockquote> Defines a section that is quoted from another source cite
<cite> Defines the title of a work
<code> Defines a piece of computer code
<del> Defines text that has been deleted from a document cite, datetime
<dfn> Specifies a term that is going to be defined within the content
<em> Defines emphasized text 
<i> Defines a part of text in an alternate voice or mood
<ins> Defines a text that has been inserted into a document cite, datetime
<kbd> Defines keyboard input
<mark> Defines marked/highlighted text
<meter> Defines a scalar measurement within a known range (a gauge) form, high, low, max, min, optimum, value
<pre> Defines preformatted text
<progress> Represents the progress of a task max, value
<q> Defines a short quotation cite
<rp> Defines what to show in browsers that do not support ruby annotations
<rt> Defines an explanation/pronunciation of characters (for East Asian typography)
<ruby> Defines a ruby annotation (for East Asian typography)
<s> Defines text that is no longer correct
<samp> Defines sample output from a computer program
<small> Defines smaller text
<strong> Defines important text
<sub> Defines subscripted text
<sup> Defines superscripted text
<template> Defines a container for content that should be hidden when the page loads
<time> Defines a specific time (or datetime) datetime
<u> Defines some text that is unarticulated and styled differently from normal text
<var> Defines a variable
<wbr> Defines a possible line-break

Forms and Input
Tag Tag Description Attributes
<form> Defines an HTML form for user input accept-charset, action, autocomplete, enctype, method, name, novalidate, onreset, onsubmit, rel, target
<input> Defines an input control accept, alt, autocomplete, autofocus, checked, dirname, disabled, form, formaction, height, list, max, maxlength, min, multiple, name, onload, onsearch, pattern, placeholder, popovertarget, popovertargetaction, readonly, required, size, src, step, type, value, width
<textarea> Defines a multiline input control (text area) autofocus, cols, dirname, disabled, form, maxlength, name, placeholder, readonly, required, rows, wrap
<button> Defines a clickable button autofocus, disabled, form, formaction, name, popovertarget, popovertargetaction, type, value
<select> Defines a drop-down list autofocus, disabled, form, multiple, name, required, size
<optgroup> Defines a group of related options in a drop-down list disabled, label, selected, value
<option> Defines an option in a drop-down list disabled, label, selected, value
<label> Defines a label for an <input> element for, form
<fieldset> Groups related elements in a form disabled, form, name
<legend> Defines a caption for a <fieldset> element
<datalist> Specifies a list of pre-defined options for input controls
<output> Defines the result of a calculation for, form, name

Frames
Tag Description Attributes
<iframe> Defines an inline frame height, name, onload, sandbox, src, srcdoc, width

Images
Tag Description Attributes
<img> Defines an image alt, height, ismap, onabort, onerror, onload, sizes, src, srcset, usemap, width
<map> Defines a client-side image map name
<area> Defines an area inside an image map alt, coords, download, href, hreflang, media, rel, shape, target
<canvas> Used to draw graphics, on the fly, via scripting (usually JavaScript) height, width
<figcaption> Defines a caption for a <figure> element
<figure> Specifies self-contained content
<picture> Defines a container for multiple image resources
<svg> Defines a container for SVG graphics

Audio / Video
Tag Description Attributes
<audio> Defines sound content autoplay, controls, loop, muted, oncanplaythrough, onabort, oncanplay, onemptied, onended, ondurationchange, onloadeddata, onerror, onloadstart, onloadedmetadata, onplaying, onpause, onplay, onratechange, onprogress, onstalled, onseeked, onseeking, ontimeupdate, onsuspend, onwaiting, preload, onvolumechange src
<source> Defines multiple media resources for media elements (<video>, <audio> and <picture>) media, sizes, src, srcset, type
<track> Defines text tracks for media elements (<video> and <audio>) default, kind, label, oncuechange, src, srclang
<video> Defines a video or movie autoplay, controls, height, loop, muted, onabort, oncanplay, oncanplaythrough, ondurationchange, onemptied, onended, onerror, onloadeddata, onloadedmetadata, onloadstart, onpause, onplay, onplaying, onprogress, onratechange, onseeked, onseeking, onstalled, onsuspend, ontimeupdate, onvolumechange, onwaiting, poster, preload, src, width

Links
Tag Description Attributes
<a> Defines a hyperlink download, href, hreflang, media, rel, target, type
<nav> Defines navigation links

Lists
Tag Description Attributes
<menu> Defines an alternative unordered list type
<ul> Defines an unordered list
<ol> Defines an ordered list reversed, start
<li> Defines a list item href, hreflang, media, onload, rel, sizes, type, value
<dl> Defines a description list
<dt> Defines a term/name in a description list
<dd> Defines a description of a term/name in a description list

Tables
Tag Description Attributes
<table> Defines a table
<caption> Defines a table caption
<th> Defines a header cell in a table colspan, headers, rowspan, scope
<tr> Defines a row in a table
<td> Defines a cell in a table colspan, headers, rowspan
<thead> Groups the header content in a table
<tbody> Groups the body content in a table
<tfoot> Groups the footer content in a table
<col> Specifies column properties for each column within a <colgroup> element span
<colgroup> Specifies a group of one or more columns in a table for formatting span

Styles and Semantics
Tag Description Attributes
<style> Defines style information for a document media, onerror, onload, type
<div> Defines a section in a document
<span> Defines a section in a document
<header> Defines a header for a document or section
<hgroup> Defines a header and related content
<footer> Defines a footer for a document or section
<main> Specifies the main content of a document
<section> Defines a section in a document
<search> Defines a search section
<article> Defines an article
<aside> Defines content aside from the page content
<details> Defines additional details that the user can view or hide
<dialog> Defines a dialog box or window
<summary> Defines a visible heading for a <details> element ontoggle, open
<data> Adds a machine-readable translation of a given content

Meta Info
Tag Description Attributes
<head> Defines information about the document
<meta> Defines metadata about an HTML document charset, content, http-equiv, name
<link> Defines the relationship between a document and an external resource (most used to link to style sheets) href, hreflang, media, onload, rel, sizes, type
<base> Specifies the base URL/target for all relative URLs in a document href, target

Programming
Tag Description Attributes
<script> Defines a client-side script async, charset, defer, onerror, onload, src, type
<noscript> Defines an alternate content for users that do not support client-side scripts
<embed> Defines a container for an external resource height, onabort, oncanplay, onerror, src, type, width
<object> Defines a container for an external resource data, form, height, name, onabort, oncanplay onerror, type usemap, width
<param> Defines a parameter for an object name, value
