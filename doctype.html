<!DOCTYPE>

  • Syntax:
    <!DOCTYPE html>
  • It is document type declaration
  • It is not case-sensitive
  • It tells the browser: "This document is written in HTML5". so render it accordingly
  • Must be written at the top of the file i.e. first line of the file
  • Without it, browser goes into "Quirks Mode" i.e. layout may break or behave inconsistently
  • with it, browser uses "Standards Mode (follows modern HTML/CSS rules)" i.e. proper, modern rendering
