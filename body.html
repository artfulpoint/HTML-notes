<body>

  • Basic structure of document

    <!DOCTYPE HTML>
    <html>
    <head>
    <title> My Title </title>
    < /head>
    <body>
    content
    </body>
    </html>
  • main content container element of a webpage
  • everything user sees on the screen is inside <body>
  • container(paired) tag
  • neither block-level nor inline
  • only one <body> per page
  • comes after <head>
  • visible elements goes inside <body> like:
    • text content
    • tabular content
    • structure/layout
    • links/navigation
    • media
    • forms
    • scripts
    types of attributes it uses:
    • global attributes
    • event attributes
    role of body is:
  • container for UI(user interface)and user interaction area
  • rendering zone
