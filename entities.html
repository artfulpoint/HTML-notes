HTML Entities

Some characters are reserved in HTML. Like, if you use the less than (<) or greater than (>) signs in your HTML text, the browser might mix them with tags. Entity names or entity numbers can be used to display reserved HTML characters to avoid any mix-up.

Entities are case-sensitive

Entity Name Syntax

&entity_name;

Entity Number Syntax

&#entity_number;

If you write 10 spaces in your text, the browser will remove 9 of them. To add real spaces to your text, you can use the &nbsp; character entity. Some commonly used entities are listed below.
