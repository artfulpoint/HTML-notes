<p>

    syntax:
  • <p>this is a paragraph</p>
  • defines paragraph of text
  • block-level element
  • container(paired) tag
  • displays text content
  • automatically adds spacing(margin) before and after
  • purpose:
    • group sentences
    • display readable text blocks
    • improve structure & readability
  • rules:
    • cannot contain block elements
  • attributes it allows:
    • global atributes
    • event atributes
    • ARIA atributes
