<title>

  • Syntax :
    <title> My Title </title>
  • defines the title of the page
  • appears at:
    • browser tab
    • search engine results
    • bookmarks
  • metadata element
  • a container(paired) tag
  • neither block-level nor inline
  • not visible inside webpage
  • must be inside <head>
  • only one <title> per webpage
  • search uses for page headline and for ranking factor
  • helps users to dentify tabs and navigate multiple pages
  • title appars as preview text upon sharing its link
  • keep short:50-60 characters; use keywords; make it meaningful
  • should have different for different page
  • uses global attributes
  • its small but powerful as it represents your page, affects SEO, impacts user experience
