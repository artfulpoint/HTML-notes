<h1> to <h6>

  • They are heading elements
  • used to define titles and subheadings
  • block-level elements
  • container(paired) tags
  • visible on webpage
  • used for structure and also have semantic meaning; are not styling(designing) tools
  • uses attributes:
    • global attributes
    • event attributes
    • ARIA attributes
    • Tag Importance Size
    <h1> highest largest
    <h2> ↓ smaller
    <h3> ↓ smaller
    <h4> ↓ smaller
    <h5> ↓ smaller
    <h6> lowest smallest
  • SEO uses for understanding page structure and rank content
  • Screen readers use it to navigate page quickly
  • help users scan content easily

Best practice

  • use only one <h1> on a page
  • follow order h1,h2...h6
  • don't use for styling (use CSS), headings have some meaning attached to it

Behind the scene

  • browser + search engines create a document outline from headings
