Introduction to HTML

What is HTML?

  • HTML stands for Hyper Text Markup Language
  • HTML is the standard markup language for creating Web pages
  • HTML describes the structure of a Web page
  • HTML consists of a series of elements
  • HTML elements tell the browser how to display the content

Boiler Plate - Basic Syntax of a Webpage

<!DOCTYPE HTML>
<html>
<head>
</head>
<body>
</body>
</html>

<!DOCTYPE HTML> declaration represents the document type, and helps browsers to display web pages correctly. It is not an element but an instruction to browser.

<html> element is the root element and it defines the whole HTML document

<head> element acts as a container for everything you want to include on the HTML page, that isn't the content the page will show to viewers. This includes keywords and a page description that would appear in search results, CSS to style content, character set declarations, and more

<body> element defines the document's body.This contains all the content that displays on the page, including text, images, videos, games, playable audio tracks, or whatever else.

Tag Anatomy

Tag is just the keyword inside angle brackets

  • Opening tag example: <p>
  • Closing tag example: </p>
  • Empty tag example: <br>

Element Anatomy

  • Opening tag
  • Content
  • Closing tag

Element: Opening tag + Content + Closing tag

<tagName> content </tagName>

Elements building blocks of HTML that describes and aid in the structure of a webpage

some elements that do not have content and closing tag are called empty tags or empty tags and others with opening and closing tags and content within them are called container elements or paired elements

elements that always start on a new line and take up the full available width are block-level elements and elements that do not start on a new line and only take up as much width as necessary for their content are inline elements

structure elements(like <div>, <span>) define the layout and visual organization of a page without describing what that content is, while semantic elements (like <article>, <nav>, <header>) describe the meaning and purpose of the content to browser and developer and upside of it, is helpful in SEO,better accessibility for assistive technologies and cleaner code readability

We can nest elements in other elements, like we did in boiler plate. the element that is nested in other element is called child element and the containing element is called parent element

Attribute Anatomy

Attributes contain extra information about the element.

  • Attribute is contained in opening tag.
  • Space between attribute-name and the element-name.
  • Attribute-name, followed by an equal sign.
  • Attribute-value, wrapped with opening and closing quote marks.

<tagName attribute-Name = "attribute-Value">
