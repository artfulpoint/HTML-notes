Syntax :
<!-- this is a comment -->
  • It is an HTML comment
  • used for:
    • write notes
    • explain code
    • temporarily disable code
  • can be used:
    • inside <head>
    • inside <body>
    • between elements
  • not HTML element
  • neither block-level nor inline
  • no attributes can be used
  • not visible on webpage
  • visible in page source
  • ignored by browser
  • common uses are:
    • documentation
    • debugging
  • can not:
    • nest another comment
    • contain -- inside a comment
