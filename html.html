<html>

  • <html> is the root element of an HTML document
  • Comes after DOCTYPE
  • It wraps everything on the page (except DOCTYPE)
  • It is a container(paired) tag
  • Syntax :

    <html>
    ...
    </html>
  • Neither block-level nor inline element
  • not visible on webpage
  • Contains:
    • <head> (metadata)
    • <body> (visible content)
  • Only one <html> tag per page
  • It can use global attributes. Some have practical meaning to use and others are pointless. Some meaningful ones like:
    • lang
    • dir
    • id
    • class
    • data-*

Behind the scenes

  • Browser creates a DOM tree like:
    • html
    |
    |-- head
    |
    --- body
  • <html> is top node(root)
