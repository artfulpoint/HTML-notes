<head>

    Syntax :
    <html>
    <head>
    ...
    </head>
    </html>
  • It is a metadata container
  • stores information about the webpage
  • not visible on the webpage
  • a container(paired) tag
  • neither block-level nor inline
  • Comes before <body>
  • appears only once on a webpage
  • can only contain metadata elements
  • order of metadata elements matters, recommended order is:
    1. character set
    2. compatibility/viewport
    3. title
    4. description/SEO meta tags
    5. CSS/stylesheets
    6. preload/preconnect links
    7. scripts
  • visible elements don't come in <head> , they belong in <body>
  • prepares & configures the resources for a webpage

List of elements allowed:

  • <title>
  • <meta>
  • <link>
  • <style>
  • <script>
  • <base>
  • <noscript>

List of attributes allowed(global):

  • id
  • class
  • style

Behind the scenes

  • Browser reads <head> first to:
    • load CSS
    • load scripts
    • set page title
    • understand encoding
